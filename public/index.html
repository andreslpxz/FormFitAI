✦ Key Features
🦴

Smart Skeleton Overlay

33-point skeleton drawn in real-time on Compose Canvas. Problematic limbs turn red; perfect form shows green.

🔢

Automatic Rep Counting

State machine per exercise (STANDING → DESCENDING → BOTTOM → ASCENDING → CONFIRMED). Handles partial reps gracefully.

📐

Angle-based Form Check

Knee, hip, elbow, and shoulder angles computed with atan2 trigonometry. Per-segment GOOD/WARNING/ERROR signals.

⚡

GPU Acceleration

NNAPI / GPU Delegate configured for Snapdragon chips. Inference runs off the main thread maintaining 60 FPS preview.

🔐

Supabase Auth

Google OAuth, Email/Password, and Magic Link sign-in. Session persists across launches. User profiles stored in Postgres.

💳

Stripe Subscriptions

Free & Pro tiers. Stripe Checkout via Edge Functions. Webhook updates subscription status in Supabase in real-time.

📋

Custom Routines

Build routines from any exercises. Set reps, sets, and rest times. Drag to reorder. Sync to cloud for all devices.

📊

Progress Dashboard

Streak heatmap, reps-over-time charts (Vico), personal bests per exercise, avg form score, calories estimate.

🎙️

Audio & Haptics

Beep on rep count, warning sound for bad form, set-completion fanfare. Haptic feedback on milestone events.
